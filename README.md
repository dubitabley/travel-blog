# Simple travel blog!

The main point of this is that I can update this on mobile!

## Notes

- Docs for zine are [here](https://zine-ssg.io/docs/). To run, use `zine` to serve locally.
- To add a blog post, add .smd files with the
  content under the blog folder. Or if we want images, add a folder and
  put index.smd inside the folder and add them the typical markdown way.
